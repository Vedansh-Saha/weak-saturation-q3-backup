# GitHub and archival release checklist

1. Create the public repository `weak-saturation-q3`.
2. Upload the repository contents, preserving the directory structure.
3. Verify `CITATION.cff` appears at the repository root.
4. Create a Git tag `v1.0.0-paper` from the exact commit corresponding to the submitted manuscript.
5. Create a GitHub release named `v1.0.0-paper`.
6. Enable the repository in Zenodo and archive that GitHub release.
7. Record the DOI assigned to the archived release.
8. Add the GitHub URL and Zenodo DOI to the manuscript's code-availability statement.
9. Add a bibliography entry for the archived computational materials.
10. Regenerate the PDF, verify the link text and bibliography, and submit that exact PDF with the exact release tag.
