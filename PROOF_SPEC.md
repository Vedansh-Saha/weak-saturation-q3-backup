# Proof Specification

> **Main Theorem**
> 
> $$\text{wsat}(K_9, Q_3) = 16, \qquad \text{wsat}(K_{10}, Q_3) = 18, \qquad \text{wsat}(K_{11}, Q_3) = 19$$

---

## Definitions and Normalization

Let $C \cong Q_3$ be the canonical cube on vertices $0, \dots, 7$ and let $e^* = 01$. Put:

$$U_n = E(K_n) \setminus E(C)$$

If the first edge in a legal weak-saturation order is mapped to $01$, then $E(C) \setminus \{01\}$ is initially present.

For each labelled cube $Q \subseteq K_n$, define:

$$M(Q) = E(Q) \cap U_n$$

The outside closure is generated by all Horn implications:

$$M(Q) \setminus \{e\} \to e, \qquad e \in M(Q)$$

*Note: Duplicate masks give identical implications and may be merged.*

The sequential equivalence and seed identity are:

$$\text{cl}_n(S) = U_n \iff (C - e^*) \cup S \text{ saturates after } e^* \text{ is added}$$
and

$$\text{wsat}(K_n, Q_3) = 11 + \sigma_n, \qquad \sigma_n = \min \{ \vert{}S\vert{} : \text{cl}_n(S) = U_n \}$$

---

## Closure Algorithm

The implementation maintains the current set $T$ and, for each implication $A \to e$, the number of antecedent edges already in $T$. An edge entering $T$ is queued once. Whenever every edge of an antecedent $A$ has entered $T$, its target is inserted.

Correctness follows from two invariants:

1. **Validity:** Every inserted edge is justified by an implication whose antecedent is already contained in $T$; hence the computed set is contained in the mathematical closure.
2. **Completeness:** At termination, every implication with antecedent contained in $T$ has its target in $T$; hence $T$ is closed, so it contains the least closed superset of the seed.

At most $\vert{}U_n\vert{}$ edge insertions occur.

---

## Upper-Bound Certificates

For each certificate, every missing edge is supplied with an injective map:

$$\varphi_i : V(Q_3) \to V(K_n)$$

with

$$\varphi_i(0)\varphi_i(1) = e_i$$

and

$$\varphi_i(E(Q_3) \setminus \{01\}) \subseteq E(F_0) \cup \{e_1, \dots, e_{i-1}\}$$

This is a finite certificate criterion: the image is a cube and exactly the target edge is required at step $i$.

The distributed witness tables give all maps and dependencies for $n = 9, 10, 11$; `verify_witness_tables.py` checks injectivity, cube-image equality, target equality, initial-edge membership, dependency indices, and final completeness.

## Results by Graph Size

### $n = 9$

$$\vert{}U_9\vert{} = 24, \qquad \binom{24}{4} = 10{,}626, \qquad \binom{24}{5} = 42{,}504$$

- **Exact Scan:** The primary scan finds zero percolating four-edge seeds and a maximum closure size of 16. 
- **Independent Verification:** The same four-edge exclusion is obtained by an independent Go implementation using explicit edge lists and queue-indexed implications. 
- **Five-edge Layer:** Contains 6,864 percolating seeds.
- **Checker Verification:** The graph-level Python checker enumerates all $840 \binom{9}{8} = 7{,}560$ labelled copies of $Q_3$ in $K_9$ and verifies that the initial graph is $Q_3$-free and that the certificate is legal.

$$\sigma_9 = 5 \implies \text{wsat}(K_9, Q_3) = 16$$

---

### $n = 10$

$$\vert{}U_{10}\vert{} = 33, \qquad \binom{33}{6} = 1{,}107{,}568$$

- **Symmetry Reduction:** The order-8 marked-cube stabilizer acts on $U_{10}$. Canonicalization yields 146,131 six-edge orbit representatives, none with full closure; the maximum closure has 25 outside edges.
- **Upper Bound & Verification:** The explicit 18-edge certificate gives the matching upper bound. The independent graph-level certificate check enumerates 37,800 labelled cube copies.

$$\sigma_{10} = 7 \implies \text{wsat}(K_{10}, Q_3) = 18$$

---

### $n = 11$

$$\vert{}U_{11}\vert{} = 43, \qquad \binom{43}{7} = 32{,}224{,}114$$

- **Stabilizer & Layers:** The marked-cube stabilizer has order 24. The complete six-edge orbit layer contains 300,563 representatives. Adjoining one edge to every representative produces 11,120,831 children before deduplication and 1,498,208 seven-edge orbit representatives afterwards. 
- **Max Closure:** No seven-edge representative has full closure; the maximum closure has 33 outside edges.
- **Burnside Verification:** Burnside's lemma independently confirms:

  $$\frac{7{,}213{,}512}{24} = 300{,}563, \qquad \frac{35{,}956{,}992}{24} = 1{,}498{,}208$$

- **Upper Bound:** The explicit 19-edge certificate supplies the upper bound.

$$\sigma_{11} = 8 \implies \text{wsat}(K_{11}, Q_3) = 19$$

---

## General Extension

After completing a weakly saturated graph on $n$ old vertices to $K_n$, add a new vertex $x$ with two initial edges $xa, xb$. For any target $xy$, choose four further old vertices and embed $Q_3$ with $x$ replacing a cube vertex whose two other cube neighbours are $a$ and $b$. All cube edges except $xy$ are then present. 

Thus:

$$\text{wsat}(K_{n+1}, Q_3) \le \text{wsat}(K_n, Q_3) + 2$$

Which, combined with the $n = 11$ certificate, yields:

$$\text{wsat}(K_n, Q_3) \le 2n - 3 \qquad (n \ge 11)$$

## Analytic Bounds

For $Q_3$, the Terekhov–Zhukovskii invariant gives:

$$e_i = 2, 4, 6, 7, 9, 10, 11 \qquad (1 \le i \le 7)$$

And hence:

$$\min_i \frac{e_i}{i} = \frac{11}{7}$$

The corresponding asymptotic slope satisfies:

$$\frac{11}{7} \le c_{Q_3} \le 2$$

The associated maximal subadditive lower-bound function provides the finite analytic bounds:

| Graph | Analytic Bound | Exact Value |
| :--- | :--- | :--- |
| $\text{wsat}(K_9, Q_3)$ | $\ge 13$ | **16** |
| $\text{wsat}(K_{10}, Q_3)$ | $\ge 15$ | **18** |
| $\text{wsat}(K_{11}, Q_3)$ | $\ge 17$ | **19** |

*Note: The exact values 16, 18, and 19 require the finite exhaustive exclusions recorded above.*
